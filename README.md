# 🐍 Classificador de Idade

> Programa desenvolvido em Python para classificar uma pessoa de acordo com sua idade.

## 🎯 Objetivo
Praticar estruturas condicionais e operadores de comparação, criando um sistema capaz de identificar diferentes faixas etárias.

## 📚 Conceitos estudados
- Variáveis
- Entrada de dados com `input()`
- Conversão de tipos com `int()`
- Estruturas condicionais (`if`, `elif` e `else`)
- Operadores relacionais
- F-strings

## ⚙️ Funcionamento
1. O programa solicita a idade do usuário.
2. Converte a entrada para um número inteiro.
3. Analisa a idade utilizando condições.
4. Determina a categoria correspondente.
5. Exibe o resultado no terminal.

## 📊 Classificação

| Faixa etária | Categoria |
|---|---|
| 0 a 12 anos | Criança |
| 13 a 17 anos | Adolescente |
| 18 a 59 anos | Adulto |
| 60 anos ou mais | Idoso |
| Idade negativa | Inválida |

## 💻 Exemplo de execução

```text
Digite a sua idade: 16
Categoria: Você é um adolescente
```

## 🧠 Aprendizado
Com este exercício, pratiquei a utilização de estruturas condicionais para criar diferentes caminhos de execução, além de aprender a comparar valores dentro de intervalos numéricos.

## 🚀 Possível melhoria
Implementar uma validação para impedir entradas que não sejam números inteiros.
